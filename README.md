# TNSH-FFT

高二自然組「簡易樂器製作 + FFT 頻譜分析」課程用的手機工具。用網頁做，iOS 與 Android 共用同一套程式，不需要上架 App Store。

網站：https://jaydu1981.github.io/TNSH-FFT/

## 目錄

| 資料夾 | 內容 | 狀態 |
|---|---|---|
| [`mic-check/`](mic-check/) | 第一步驗證：手機收音會不會被系統自動修改（自動增益、降噪、回音消除） | 課堂測試中 |
| （之後） | 頻譜分析工具：即時頻譜、錄音、重播、比較、匯出 | 規劃中 |
